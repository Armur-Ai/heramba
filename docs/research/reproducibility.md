# Reproducibility

Every figure in the [research report](research-report.md) is regenerated by a
committed command. There is no hand-edited spreadsheet between raw measurements
and the reported tables — the analysis *is* the code.

## Environment

- Go 1.25+ (CI runs 1.25.x and 1.27.x; reference runs used `go1.27.2 darwin/arm64`).
- Clone the repo; no network, no external services, no credentials.
- Build the CLI: `make build` (or `go build -o bin/heramba ./cmd/heramba`).

## One-time verification

```bash
go build ./...            # clean
go vet ./...              # clean
test -z "$(gofmt -l .)"   # formatted
go test -race ./...       # 38 packages pass, no races (~50s cold)
```

## Regenerate every experiment

| Figure / table | Command | Determinism |
|---|---|---|
| Protocol & hypotheses manifest | `heramba research manifest` | exact |
| H1 coordination experiment | `heramba research coord --artifacts docs/research/artifacts/coord` | metrics byte-identical (throughput is a timing measurement) |
| H2 deception objective | `heramba research objective --artifacts docs/research/artifacts/objective` | exact |
| H3 co-evolution lab | `heramba research coevolve --artifacts docs/research/artifacts/coevolve` | exact (seeded, event-sourced) |
| R8 targets scorecard | `heramba research stats --artifacts docs/research/artifacts/scorecard` | exact (bootstrap seeded) |
| Four-baseline replay | `heramba experiment --json` | byte-identical |

### Confirming determinism yourself

```bash
# coordination metrics are stable across runs (throughput excluded):
diff <(heramba research coord --json | grep -v throughput) \
     <(heramba research coord --json | grep -v throughput) && echo IDENTICAL

# the four-baseline experiment is byte-identical:
heramba experiment --json | shasum
heramba experiment --json | shasum        # same hash
```

Reference checks at `93557d5`: the coordination metrics hash to
`c24eb0fdd001c864` and `heramba experiment --json` to `1387ba652109a167` on
repeated runs.

## Immutable raw artifacts

The committed reference outputs are under
[`artifacts/`](artifacts/): `coord/`, `objective/`, `coevolve/`, and
`scorecard/`, each with the machine-readable JSON, the markdown summary, and
(for coord) the protocol manifest. Re-running the commands above overwrites them
with identical content; CI's determinism tests assert the metric fields do not
drift.

## Reproducing the safety & assurance results

```bash
go test ./internal/taint/...         # R5 injection battery (inert fixtures)
go test ./internal/edge/...          # R6 proxy correctness, resilience, SLO
make fuzz FUZZTIME=20s               # R7 fuzzing (parsers, routing, policy)
make sbom && git diff --exit-code sbom.cdx.json   # SBOM is reproducible
go test ./internal/incident/...      # R9 investigation timeline + gates
go test ./labs/...                   # R10 all eight labs (fresh-machine dry run)
```

## Nondeterminism caveats

- **Throughput** (`research coord`) and the **proxy latency SLO** (R6) are timing
  measurements and vary by machine; they are reported as measurements, not fixed
  values, and excluded from determinism checks.
- Fuzzing explores new inputs each run by design; the invariant assertions, not a
  fixed corpus, are what must hold.
