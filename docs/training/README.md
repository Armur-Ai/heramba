# Training materials

Public, reusable training content for the Heramba labs. See
[COURSE.md](COURSE.md) for the 2-day core and optional 4-day course map.

All student materials here are self-contained and run locally against the real
engine. Instructor-only materials (solution keys, challenge flags, grading
secrets, confidential proposals) are **not** in this repository — they live in a
separate private instructor repo, per the lab [public/private policy](../../labs/README.md#public-vs-private-materials).
