## Scope

This policy covers use of Armur Technologies Inc.'s names and logos associated
with this project. It does **not** assert exclusivity in any provisional codename,
and it is not a claim of trademark registration.

## Permitted

- **Nominative use**: you may use the project name truthfully to refer to the
  project (e.g., "compatible with …", "built on …").
- Unmodified official releases may be identified as such.

## Not permitted

- Using the project's name or logo in a way that implies endorsement, affiliation,
  or that a modified/forked version is an official release.
- Using any ™ or ® symbol on the project name. Do **not** use ® without a
  relevant active registration. Use "™" only when and where appropriate and
  approved.

## Modified versions

If you distribute a modified version, use your own name/branding and make clear it
is not an official Armur release.
